# Figures

All canonical theory figures are generated by:

```bash
python scripts/reproduce_figures.py --outdir build/figures
python scripts/make_pedagogical_figures.py --outdir build/figures
```

The script produces:

- the local \(t^2\) law beside the exact ridge fitness calibration;
- deterministic-selection versus diffusion exponents;
- channel evolution from standing variation;
- the explicitly phenomenological geometric-to-DMI handoff;
- a teaching diagram for \(\mathbf G\), \(\mathbf H\), and \(\mathbf S\); and
- the causal sequence from divergent selection to later intrinsic isolation.

Generated PDF and PNG files are ignored. The repository tracks sources, tests, and derivation inputs rather than binary outputs.
