# External Senecio inputs

To rerun the optional descriptive analysis, provide local copies of:

- `data_AL_Arch&Leaf_ARVersion.xlsx` — plant architecture and leaf descriptors;
- `All S. lautus soil data.xlsx` — population soil chemistry.

Pass their locations through the `--morphology` and `--soil` arguments. The v2 Git tip does not redistribute these spreadsheets; consult `docs/DATA_PROVENANCE.md` and the cited primary data archives.
