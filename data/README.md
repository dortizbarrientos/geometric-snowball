# Data

The core mathematical package has no empirical-data dependency.

`raw/senecio/README.md` explains how to supply two optional published project spreadsheets. They are not duplicated in the clean v2 tree. `derived/senecio_pair_summary.csv` contains a small descriptive summary used by the plotting smoke test.

No column in the derived summary is an estimate of fitness curvature, channel angle, or reproductive isolation.
