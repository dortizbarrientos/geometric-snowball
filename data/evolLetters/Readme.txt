Data for Walter et al.

Walter_Data_Exp1.csv
Morphological data for the parental ecotypes and the F4 hybrid. 
Family = the full-sibling family the seeds were taken from
Height = Plant height (mm)
Columns D-I = Measures used in the analysis
Columns K+ = Other outputs of Lamina not used

Walter_Data_Exp2.csv
Field performance data for parental ecotypes, and F1 and F4 hybrids.
ENV = transplant environment
block = experimental block
GRID = grid reference each seed was placed in
GENO = generation
Type = General identify for the cross types of each generation
TypeS = More specific identifier (R, Y and P represent the three independent crossing lines in the F4 hybrid)
Family = full-sibling family
Sire & Dam = Identifiers of the F3 parental generation
GE = [binary] emerged yes/no
D100 = [binary] alive at day 100 yes/no
L10 = [binary] reached seedling establishment (10 leaves) yes/no
Bud = [binary] reached maturity (produced a bud) yes/no

Columns N-S = number of days to reach each developmental stage
