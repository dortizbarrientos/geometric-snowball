Code and manuscript files for the paper:

> **Gene interactions are common yet additive prediction succeeds because evolution is local**  
> Ortiz-Barrientos & Cooper, in preparation.

## Repository structure
```
manuscript/                  LaTeX source: main text and SI
manuscript/figures/          Python figure generation script and figure PDFs
manuscript/mathematica/      Mathematica notebooks for symbolic derivations
notes/apps/                  Interactive HTML tutorial apps (pedagogical companion)
notes/prereqs/               Background reading and prerequisite tutorials
notes/github/                Git and Overleaf workflow documentation
presentation/additive/       Keynote and figures for conference presentations
presentation/letter/         ARC and general letters
```

## Reproducing the figures
```bash
pip install matplotlib numpy scipy
python manuscript/figures/figures_all_annotated.py
```
