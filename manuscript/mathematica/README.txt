Expanded Mathematica notebook for additive channels
==================================================

Files
-----
- AdditiveChannels_Expanded_Annotated.nb
    Main notebook with background, derivations, numerical checks,
    covariance-dynamics structure, introgression criterion, and export examples.
- AdditiveChannels_Expanded_Annotated.wl
    Companion Wolfram Language script.
- README.txt
    Short running guide.

How to use
----------
1. Download the .nb file.
2. Open it in Mathematica or Wolfram Desktop.
3. Evaluate from top to bottom.
4. Edit only the parameter blocks if you want new numerical examples.
